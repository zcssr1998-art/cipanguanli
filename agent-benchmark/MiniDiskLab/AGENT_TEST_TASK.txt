==================================================
一、项目目标
==================================================

开发一个叫 MiniDiskLab 的小型 Windows 磁盘分析工具。

它不是正式商业软件，而是用来验证你的 Agent 开发能力。

核心功能：
1. 用户可以选择本地任意文件夹。
2. 用户可以输入“大文件阈值”，例如 100MB、500MB、1GB。
3. 点击“开始扫描”。
4. 程序递归扫描该目录。
5. 找出达到或超过阈值的文件。
6. 按文件大小从大到小排序。
7. 显示：文件名、完整路径、文件大小、文件类型、自动说明。
8. 支持取消扫描。
9. 显示扫描状态和当前正在扫描的位置。
10. 显示已扫描文件数、发现的大文件数、跳过目录数。
11. 可以将结果导出成 CSV。

==================================================
二、自动说明功能
==================================================

不要只根据扩展名显示“视频”“图片”。

需要结合：
文件扩展名 + 路径 + 文件夹名称
进行本地规则判断，不需要调用在线 AI。

示例：
D:\Tencent Video\Download\xxx.mp4
应尽量显示：腾讯视频下载的视频资源

D:\Projects\Character01\maya\body.ma
应显示类似：Maya 3D 工程文件，可能属于角色/模型项目

D:\SteamLibrary\steamapps\common\Game\xxx.pak
应显示类似：Steam 游戏资源文件，不建议单独删除

至少支持这些类别：
- 视频
- 图片
- 压缩包
- 游戏资源
- Steam
- 腾讯视频
- Adobe 缓存
- Unreal Engine
- Unity
- Maya
- Blender
- 3D 模型资源
- 安装包
- ISO 镜像
- 日志
- 临时文件
- 未知文件

==================================================
三、必须处理的工程问题
==================================================

1. 扫描不能卡死 UI
扫描必须放到后台执行。窗口在扫描过程中仍然可以移动、点击、取消，不能因为扫描大量文件而假死。

2. 权限错误不能导致崩溃
遇到 Access Denied、PermissionError、UnauthorizedAccess 等目录时，跳过并继续扫描，同时记录跳过了多少目录。

3. 特殊目录
考虑：
- 空文件夹
- 文件扫描过程中消失
- 无权限目录
- 超长路径
- Symbolic Link / Junction
- 可能形成循环的链接
不能因为一个异常导致整个扫描失败。

4. 取消功能
用户点击“取消扫描”后，必须真正终止后台扫描任务，不能只是按钮变灰但后台仍继续运行。
