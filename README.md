# Cipanguanli / 磁盘空间诊断器

Windows 10/11 x64 本地磁盘诊断工具。目标不是做“无脑清理器”，而是回答四个问题：**什么占空间、它属于谁、能不能动、应该清理/隔离/迁移还是走官方卸载。**

## v0.3 新增

### 软件 / 游戏归属识别

- 读取 Windows 已安装程序注册表。
- 读取 Steam `appmanifest_*.acf` 与 Library 路径。
- 读取 Epic Games 本地 Manifest。
- 文件/目录如果位于已安装软件目录下，会显示软件名、识别来源、置信度和官方管理建议。
- Steam 游戏可直接打开 Steam 卸载入口；其他程序优先使用注册表卸载命令或 Windows“已安装的应用”。

### 智能安全评分与依赖提示

诊断页为大文件和大目录生成 0–100 的“处理安全分”，结合：

- 系统/程序路径
- 已安装软件归属
- 缓存/临时/下载语义
- 3D 工程、数据库、虚拟机、云盘等高风险类型
- UE / Unity 等工程结构线索

并给出“官方卸载 / 先隔离 / 优先迁移 / 禁止直接操作”等建议。

### 卸载残留线索

对 AppData / ProgramData / Cache / Temp 等区域进行保守分析：

- 未匹配当前已安装软件目录
- 缓存或应用数据特征
- 长时间未修改
- 占用较大

只输出“疑似残留”和置信度，**不会仅凭规则自动删除**。

### 空间增长历史

每次完整扫描后，本地保存一份目录快照。下一次扫描会显示：

- 上次大小
- 当前大小
- 增长量
- 增长最多的目录

可用于回答“昨天还有 200GB，今天为什么只剩 100GB”。历史保存在当前用户 LocalAppData 的 Cipanguanli 目录。

### 三档清理计划

自动生成：

- 🟢 保守：明确的低风险缓存/临时/下载线索
- 🟡 推荐：保守项 + 完全重复文件 + 高置信残留 + 低风险旧安装包/归档/视频
- 🔴 激进：进一步纳入更多长期未修改的中低风险项目

计划只是决策辅助和空间估算，不自动永久删除。

### 可恢复隔离区

大文件、大目录、旧文件、诊断项和残留线索都可先进入隔离区：

- 记录原始路径
- 支持恢复到原位置
- 原位置已有同名内容时拒绝覆盖
- 系统关键路径禁止隔离
- 跨盘依旧采用“复制 → 校验 → 删除源”的安全迁移逻辑

### 规则学习

在“诊断”页可以给某个路径手动标记用途，例如：

- 死亡搁浅素材
- 客户 A 角色工程
- ComfyUI 模型目录

软件会把该目录规则保存在本地，下次诊断优先显示用户标注。

### 资源管理器右键菜单

顶部可安装当前用户级右键菜单：

`用 Cipanguanli 分析此位置`

右键文件夹或磁盘后会直接启动程序、选中该位置并自动开始扫描；无需管理员权限写系统级注册表。

### 相似媒体候选

在完全重复（SHA-256）之外，新增“相似媒体”线索：

- 去掉 copy / 副本 / 1080p / 4K / 尾部序号等命名噪音
- 文件名主体相近
- 体积接近

它适合找改名、转码、不同分辨率的副本，但**不是内容级相似度证明**，因此只作为人工检查候选。

### 压缩收益预测

诊断页根据扩展名与内容类型给出粗略压缩收益：视频/压缩包/模型权重通常偏低，文本/日志/OBJ 等通常较高，3D 工程则按内部构成给出中等或需实测判断。

## 安全原则

1. 系统关键文件拒绝迁移和隔离。
2. 已安装软件目录优先走官方卸载/游戏平台管理。
3. 3D 工程、数据库、虚拟机、云盘等内容默认提高风险。
4. “残留”“清理计划”“相似媒体”都是辅助判断，不等于自动删除许可。
5. 不确定时优先隔离或迁移，而不是永久删除。

## 构建

项目为 `.NET 8 + WPF`：

```powershell
dotnet build .\src\Cipanguanli\Cipanguanli.csproj -c Release
```

独立 x64 EXE：

```powershell
dotnet publish .\src\Cipanguanli\Cipanguanli.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

## Windows 自动验收

GitHub Actions `windows-latest` 依次执行：

1. Release Build
2. xUnit 单元测试
3. 发布 self-contained EXE
4. 运行打包后的 EXE 功能自测
5. 自测覆盖扫描、分类、旧文件、重复文件、软件归属、用户规则、残留判断、三档清理、增长历史、隔离/恢复、安全迁移等
6. 直接启动打包后的 WPF 主窗口做 UI smoke test
7. 全部成功后才上传 Windows artifact
